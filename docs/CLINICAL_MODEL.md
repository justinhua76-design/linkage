# CLINICAL_MODEL — Levine Clinical PhenoAge (2018)

> 状态：Sprint 1，模型版本 `levine_phenoage_2018 v1.0.0`。**仅供研究和内部验证使用**，不得用于诊断或治疗决策。

## 1. 来源

Levine ME, Lu AT, Quach A, Chen BH, Assimes TL, Bandinelli S, et al. *An epigenetic biomarker of aging for lifespan and healthspan.* Aging (Albany NY). 2018;10(4):573-591. doi:[10.18632/aging.101414](https://doi.org/10.18632/aging.101414)

该文先用 NHANES III 数据构建"表型年龄"（Phenotypic Age），再用它训练 DNAm PhenoAge。本系统**只实现临床表型年龄**（9 项血液指标加实际年龄），不涉及 DNA 甲基化。

## 2. 公式（逐字实现于 `backend/app/domain/phenoage.py`）

线性预测值（模型单位见第 3 节）：

```
xb = -19.907
     - 0.0336  × 白蛋白 [g/L]
     + 0.0095  × 肌酐 [µmol/L]
     + 0.1953  × 血糖 [mmol/L]
     + 0.0954  × ln(CRP [mg/dL])
     - 0.0120  × 淋巴细胞 [%]
     + 0.0268  × MCV [fL]
     + 0.3306  × RDW [%]
     + 0.00188 × ALP [U/L]
     + 0.0554  × WBC [10³/µL]
     + 0.0804  × 实际年龄 [岁]
```

120 个月死亡风险评分（Gompertz 模型，γ = 0.0076927）：

```
M = 1 − exp( −exp(xb) × (exp(120γ) − 1) / γ )      # exp(120γ) − 1 = 1.51714
```

表型年龄：

```
PhenoAge = 141.50225 + ln( −0.00553 × ln(1 − M) ) / 0.090165
```

### 2.1 数值稳定性（与原文代数等价）

`ln(1 − M) = −H`，其中 `H = exp(xb)·(exp(120γ) − 1)/γ` 是累积风险。引擎按 `PhenoAge = 141.50225 + ln(0.00553·H)/0.090165` 计算，结果与原文公式在代数上完全相同。

这样做的原因：高风险输入下 `1 − M` 在双精度中会下溢为 0，原文写法会出现 `ln(0)`。例如参考样本 REF-05 的 `1 − M ≈ 10⁻³³⁸⁸`，按原文写法即使用 400 位十进制精度也会失败。单元测试从两个方向验证：

* 在 200 组随机生理范围输入上，稳定写法与原文逐字写法的差 < 1e-8 岁；
* 在极端样本上，原文逐字写法会失败，稳定写法给出与 400+ 位独立参考实现一致的结果。

### 2.2 常数指纹

所有常数序列化后取 SHA-256（`coefficients_sha256`），随每条结果保存，任何系数改动都可追溯。`test_published_constants_are_unchanged` 锁定全部常数。

### 2.3 常数核对与已知差异

| 来源 | 差异 | 对结果的影响 |
|---|---|---|
| 本系统 | 截距 −19.907（原文表格值） | — |

| `biolearn` 0.9.1（PyPI） | 白蛋白系数 −0.034、RDW 系数 0.3356、γ = 0.0077、`ln(1.00001 − M)` | RDW 系数差异在 RDW = 13% 时约为 0.7 岁，**不可作为参考** |

## 3. 指标、模型单位与换算

模型单位就是原文拟合时所用的单位（NHANES III：多数为国际单位，CRP 为 mg/dL）。只接受白名单中的单位，**不做任何猜测**。

| 代码 | 指标 | 模型单位 | 可接受单位 → 系数 | 可接受范围（超出则拒绝） | 通用参考区间（超出仅提示） |
|---|---|---|---|---|---|
| albumin | 白蛋白 | g/L | g/L ×1；g/dL ×10 | 10–70 | 35–52 |
| creatinine | 肌酐 | µmol/L | µmol/L ×1；mg/dL ×88.4 | 10–2000 | 45–110 |
| glucose | 空腹血糖 | mmol/L | mmol/L ×1；mg/dL ×0.05551 | 1–40 | 3.9–6.1 |
| crp | C 反应蛋白 | mg/dL（取 ln） | mg/dL ×1；mg/L ×0.1 | 0.001–50（实测值） | 0–0.5 |
| lymphocyte_pct | 淋巴细胞百分比 | % | % ×1 | 1–99 | 20–40 |
| mcv | 平均红细胞体积 | fL | fL ×1 | 50–150 | 80–100 |
| rdw | RDW-CV | % | % ×1 | 8–40 | 11.5–14.5 |
| alp | 碱性磷酸酶 | U/L | U/L ×1；µkat/L ×60 | 5–2000 | 40–130 |
| wbc | 白细胞 | 10³/µL | 10³/µL、10⁹/L ×1；cells/µL ×0.001 | 0.5–100 | 4–10 |
| age | 实际年龄 | 岁 | — | 18–110（20–84 以外给出外推警告） | — |

换算系数采用 NHANES 发布国际单位变量时使用的系数（LBDSCRSI = LBXSCR × 88.4；LBDGLUSI = LBXGLU × 0.05551）。

单位拼写会先做规范化：µ/μ/u 视为同一字符，全角符号经 NFKC 处理，忽略空白和大小写。之后仍不在白名单中的单位一律拒绝。

**明确拒绝的常见错误：**
* RDW-SD（fL）与 RDW-CV（%）是不同的量，不做换算，直接报 `UNIT_NOT_ALLOWED`；
* 淋巴细胞绝对计数（10⁹/L）不能当作百分比；以小数形式录入（例如 0.3）会因低于 1% 被拒绝；
* 数值落在可接受范围之外、但换算成另一个允许单位后合理时，错误信息会提示"请核对单位"（例如把白蛋白 4.5 填成了 g/L）。

## 4. CRP 的对数变换、零值与低于检出限

模型项是 `ln(CRP[mg/dL])`，因此 CRP **必须先换算为 mg/dL 再取对数**。

| 情形 | 处理 |
|---|---|
| 实测值 > 0 | 先换算为 mg/dL，再按可接受范围校验，然后取 ln |
| 实测值 = 0 | **拒绝**（`CRP_ZERO`），提示改为勾选"低于检出限"并填写检出限 |
| 实测值 < 0.001 mg/dL（0.01 mg/L） | 拒绝：该量级不可能是有效的实测值，应按低于检出限报告 |
| `below_lod = true` | 必须提供检出限 LOD（> 0，单位与结果相同）。LOD 按同一单位换算后，再按策略替代 |
| 低于检出限，但填写的值大于 LOD | 拒绝（`LOD_CONFLICT`） |

替代策略由环境变量 `CRP_LOD_POLICY` 设置，所用策略会随每条结果保存：

* `lod_div_sqrt2`（默认）：代入 LOD/√2，与 NHANES 的惯例一致；
* `lod`：代入 LOD 本身；
* `reject`：不计算。

使用替代值时，结果会带有警告 `CRP_BELOW_LOD_IMPUTED`，相应指标的质量状态记为 `below_lod_imputed`。

## 5. 缺失数据

Sprint 1 **不做任何插补**（CRP 低于检出限的替代除外）。九项指标或实际年龄中任何一项缺失、无效、单位错误或超出可接受范围，都返回 422 和逐项错误，**不会返回任何年龄数值**。

## 6. 输出与解读限制

* `phenoage`（完整精度）和 `phenoage_rounded`（保留 0.1 岁）；
* `phenoage_minus_chronological_age` 是简单差值，**不是**原文中的 PhenoAgeAccel。后者是对实际年龄回归后的残差，需要参考人群才能计算；
* `mortality_score` 是模型内部量，不得作为个体死亡风险告知受试者；
* PhenoAge 超出 [0, 120] 岁时给出警告 `PHENOAGE_EXTRAPOLATED`；
* 模型基于美国 NHANES 人群拟合，用于中国人群或其他人群时，需要单独做校准和验证（见 `VALIDATION_PLAN.md`）。

## 7. 确定性保证

* 年龄只由 `app/domain/phenoage.py` 的闭式公式计算：没有随机性，没有 I/O，不调用任何外部服务；
* **禁止调用大语言模型参与年龄计算**。测试 `test_no_llm_dependencies` 会扫描源码和依赖，发现 LLM SDK 即判失败。
