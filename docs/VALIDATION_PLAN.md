# VALIDATION_PLAN — PhenoAge 引擎验证计划

## 1. 目标与验收精度

| 项目 | 约定精度 |
|---|---|
| PhenoAge 与独立参考实现的差 | **< 1e-6 岁**（界面显示精度为 0.1 岁） |
| 120 个月死亡评分 M | < 1e-9 |
| 线性预测值 xb | < 1e-9 |
| 国际单位与美制单位录入同一受试者 | PhenoAge 之差 < 1e-9 岁 |

## 2. 已完成（Sprint 1，自动化）

### 2.1 独立参考实现

`backend/tests/reference_impl.py` 与应用代码**完全不共享代码**：

* 单独抄录的系数表；
* Python `decimal` 任意精度运算，精度自适应（可高达数千位），保证原文写法中的 `1 − M` 不会下溢；
* 按原文公式逐字计算，先算 M，再由 M 求 PhenoAge。

固定参考样本存放在 `backend/tests/fixtures/phenoage_reference_cases.json`，共 8 例合成受试者，覆盖：健康中年、年轻低炎症、老年高风险、NHANES 类人群均值、极端高风险（数值稳定性）、低 hs-CRP、训练范围上下界（20 岁、84 岁）。样本由 `python -m tests.fixtures.generate_reference_cases` 生成，另有一个测试用于防止有人手工修改该文件。

## 4. 变更控制

* 修改任何常数都必须同时升级 `MODEL_VERSION` 并重新生成参考样本，再经两人审阅；`coefficients_sha256` 会随之变化，旧结果仍可追溯到当时的常数。
* 参考样本文件只能通过生成脚本更新。
